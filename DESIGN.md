
# DESIGN.md

## Design System
Name: NIGHT//SYSTEM

## Visual Direction
Cinematic technical portfolio combining:
- Software engineering
- Cybersecurity
- Hardware visualization
- Premium product storytelling

## Colors
- Background: near-black
- Surface: charcoal
- Text: warm white
- Muted text: cool gray
- Accent: restrained amber/orange
- Status: semantic colors only when needed

## Typography
- Large editorial hero headlines
- Compact technical labels
- Clear readable body text
- No excessive decorative typography

## Layout
- Spacious sections
- Strong vertical rhythm
- Responsive grids
- Focused content hierarchy

## Motion
- Smooth entrance reveals
- Controlled parallax
- Camera-like transitions for project scenes
- No motion required to understand content
- Reduced-motion alternative

## 3D Principles
- Use 3D to explain technical systems.
- Procedural/original hardware-inspired assets initially.
- Keep scenes bounded and performant.
- Every major 3D scene must have a fallback.

## Component Patterns
- Technical metadata strips
- Cinematic project cards
- Annotation panels
- System diagrams
- Accessible CTA buttons
